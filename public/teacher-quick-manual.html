STANDARD FLOW

一节课开始前的标准顺序

不要颠倒。当前系统已经固定为“先名单、后开放”的教师流程。

1. 创建或进入本次活动

  1. 进入教师后台。
  2. 创建新的“经济学基础”活动，或进入已有活动。
  3. 新活动创建后，学生入口默认锁定，这是正常保护机制。

2. 先导入实名名单

支持 Excel / CSV。最稳的列名只有两列：

  • 姓名
  • 学号
名单导入后，系统会自动开启实名限制并关闭 PIN；名单外学生不能进入课程。

3. 再发邀请码

只有名单到位后，邀请码和学生二维码才会解锁。学生正式入口固定为：

  • https://classshow-student.pages.dev/student

学生只填写：姓名、学号、邀请码。

4. 开课后主要看三块

  • 学习榜 / 活跃榜
  • 上次保存时间 / 待保存状态
  • 模块综合复盘证据
TEACHING CONTROL

你最常用的两个控制点

先把课堂放通，再判断学生到底是没学、在学未保存，还是已经完成并保存。

名单与邀请码

如果学生说“进不去课程”，先看：

  • 本次活动是否已经导入实名名单
  • 学生姓名、学号是否和 Excel 完全一致
  • 邀请码是否发对

保存状态与学习时长

学生端学习记录是本地优先、手动保存到云端。老师后台里的：

  • 上次保存时间：最后一次云端落库时间
  • 待保存状态：学生可能已学，但还没点“保存记录”
MODULE REVIEW

模块综合复盘怎么处理

这部分已经接进教师后台，可直接形成老师处理闭环。

你可以做什么

  • 按姓名 / 学号 / 班级 / 小组搜索
  • 筛选待老师处理、近 24 小时新保存、老师已读闭环
  • 写点评
  • 标记已读
  • 导出当前视图为 Excel / CSV

课后建议顺序

  1. 先看“近 24 小时新保存”
  2. 再看“待老师处理”
  3. 给重点学生写简短点评
  4. 标记已读，形成闭环
