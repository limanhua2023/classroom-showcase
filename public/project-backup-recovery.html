CRITICAL CONFIG

关键配置与恢复说明

代码 ZIP 默认不包含 secrets，secrets bundle 也需要 passphrase 才能恢复。因此要把“恢复路径”说清楚，而不是假设它自动回来。

Render 生产环境变量

至少恢复：APP_SECRET、SUPER_ADMIN_PASSWORD、SUPABASE_URL、SUPABASE_ANON_KEY、SUPABASE_SERVICE_ROLE_KEY、R2 归档变量、视频转码变量。

Supabase 高权限密钥

恢复时使用 sb_secret_... 作为后端高权限 key，不要把 sb_publishable_... 当成恢复密钥。怀疑泄露时先旋转再回填。

Cloudflare R2 S3 凭证

恢复时需要：bucket 名称、endpoint、Access Key ID、Secret Access Key。不要把通用 API token 当成 S3 Access Key 使用。

本地备份代理配置

恢复新电脑后，重新检查 .env.local-backup.local、.env.project-backup.local、.env.secrets-backup.local，并重新安装 Windows 计划任务。
