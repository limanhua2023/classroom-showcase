PRIMARY DUTIES

超级管理员主要负责什么

超管只负责系统层，不负责具体课堂教学细节。

课程注册表

  • 新增课程
  • 修改课程名称和 slug
  • 启用 / 停用课程
  • 调整课程排序
  • 挂载 scaffold

运维与恢复

  • 查看备份与恢复总览
  • 查看项目代码快照状态
  • 查看加密 secrets 备份状态
  • 查看 Render egress / R2 / 热存储状态
RELEASE CHECK

发布前你至少要确认什么

每次重要上线前，先确认这套系统还能从学生、教师、超管三个面正常走通。

最小检查清单

  1. 学生站可打开
  2. 教师后台可登录
  3. 超管登录正常
  4. /api/health 正常
  5. 最近一次项目代码备份正常
  6. 最近一次 secrets 备份正常
  7. 最近一次业务数据本地备份正常

严格验收命令

需要完整发布验收时，跑这一条：

$env:CLASSSHOW_ENABLE_SUPER_ADMIN_SMOKE='1'
$env:CLASSSHOW_SUPER_ADMIN_PASSWORD='你的超管密码'
node scripts/check-public-readiness.mjs https://classshow-student.pages.dev https://classroom-showcase.onrender.com

ROLLBACK

升级失败时怎么回到稳定版

先回滚代码，再按需恢复 secrets 和业务数据。

代码回滚

git fetch origin
git checkout main
git reset --hard restore-2026-06-01-stable-system-signoff
git push --force-with-lease origin main

恢复资产

  • 项目代码快照
  • secrets bundle
  • 本地业务数据备份
