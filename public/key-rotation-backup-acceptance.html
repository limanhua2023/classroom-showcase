密钥轮换后 6 步重验收

顺序不要乱。先确认线上读到新密钥，再补本地备份，再重装计划任务，最后做真实验收。

1. 更新 Render 生产变量

至少检查 SUPABASE_SERVICE_ROLE_KEY、ARCHIVE_S3_ACCESS_KEY_ID、ARCHIVE_S3_SECRET_ACCESS_KEY、SUPER_ADMIN_PASSWORD。保存后必须重新部署。

2. 更新本地备份源文件

同步更新 .env.project-backup.local、.env.secrets-backup.local、.env.local-backup.local、.env.render-backup.local，避免云端和本地的密钥版本不一致。

3. 立即重跑代码与 secrets 备份

执行 npm run backup:project 和 npm run backup:secrets，确保新的密钥版本已经写入最新备份包，而不是继续沿用旧快照。

4. 重装 3 个计划任务

重新安装 local / project / secrets 三个 Windows 计划任务，避免旧任务缓存了过期环境变量。

5. 做一次教师侧真实动作验收

在教师后台确认活动快照下载、写入云端、归档/恢复入口和恢复手册入口都可正常打开。不要只看健康页。

6. 核对健康页与覆盖率

目标是看到维护密钥为 service_role、归档提供方为已配置、项目备份/Secrets 备份/本地备份全为健康，Secrets 覆盖率为 4/4。
